iLabs nRF52 Arduino BSP

Arduino Board Manager index

This page hosts the board-manager index for the iLabs fork of the Adafruit nRF52 Arduino Board Support Package. It adds support for the Challenger 840 BLE and Connectivity 840 boards on top of the full Adafruit Bluefruit / Feather / CLUE / Circuit Playground / ItsyBitsy / LED Glasses lineup.

Installing in the Arduino IDE

Add this URL under File → Preferences → Additional Board Manager URLs:

https://pontuso.github.io/iLabs_nRF52_Arduino/package_ilabs-nrf52_index.json

Then open Tools → Board → Boards Manager…, search for iLabs, and install the latest version.
